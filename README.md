# Gamma 2 - Crop Yield Prediction

## Project Overview

This industry training capstone project focuses on developing a machine learning solution for crop yield prediction.

The objectives are to:

- Predict crop yield using environmental and agricultural variables.
- Identify the factors that most influence crop yield.
- Compare baseline and advanced regression models.
- Translate findings into actionable agricultural and business recommendations.
- Develop an interactive Streamlit dashboard for communicating results and generating predictions.
